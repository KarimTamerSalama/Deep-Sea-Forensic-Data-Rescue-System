# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability, firmware bug, or hardware safety issue in the Autonomous Deep-Sea Forensic & Exploration Data Rescue System, please report it responsibly by sending an email directly to the maintainer at: **[kt181382@gmail.com](mailto:kt181382@gmail.com)** (or by opening a private security advisory on GitHub).

- **Expected Response Time:** Within 72 hours of report submission.
- **Scope:** Includes the ESP32 MicroPython firmware (`ESP32_CODE.py`), SPI pressure sensor communication, and solenoid fail-safe actuation logic.
